Bootsharp C# WASM — 4-worker thread pool

A small JS-side pool manages 4 dedicated Web Workers, each booting its own Bootsharp .NET runtime instance. Jobs beyond 4 concurrent queue up and are dispatched the moment a worker frees. Every job is a synchronous BusyWait(ms) call inside its worker — the main thread stays responsive throughout, as shown by the heartbeat below.
